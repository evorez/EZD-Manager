# Development sequence

1. **Foundation** — repo structure, Compose shell, GitHub Actions APK + module ZIP. (Current.)
2. **Verified controls** — capability discovery, per-cluster CPU, GPU/display where exposed, telemetry, profiles, reversible writes, guarded boot persistence.
3. **Per-app profiles** — foreground detection and scoped profile apply/restore.
4. **Charging** — only supported charge/current nodes; read-back and reset.
5. **Property profiles** — scoped, opt-in local device property overlays; no integrity/anti-cheat evasion.
6. **Release polish** — UI, supplied brand assets, docs, MIT license, device validation.
